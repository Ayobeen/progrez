# Progrez demo script

## 1. Open the learning space

Start the app and open http://127.0.0.1:8000/. Select **Tunde**, then **Continue course: Data Analysis Foundations**. If you want a clean demonstration, use **Demo lab → Reset this learner** and confirm. Reset is for sample data only.

Show the current goal, next lesson, momentum, and two demonstrated skills. The starting history is explicitly marked as sample learning history.

## 2. Change the signals

Open **Demo lab → Simulate Tunde’s challenge**.

The application records three failures, longer sessions, and hint requests. Momentum drops, and the engine ranks explanations. With the weak diagnostic foundation and repeated concept errors, the prerequisite-gap explanation takes priority over generic difficulty.

Explain: “This is a rule score with evidence, not a claim that we know what the learner is thinking.”

## 3. Let the learner decide

On the check-in, show the evidence and ranked candidates. Choose **Yes** and keep the foundation-gap barrier. Alternatively, choose **No** and select limited time to demonstrate that the learner can correct the inference.

Select **Build my comeback plan**.

## 4. Start the recovery

The plan includes a short review, a guided example, and the real checkpoint. Session durations fit the learner’s time budget. With no AI gateway configured, the source is clearly labeled **Curated recovery template**.

Select **Start my comeback**. The app preserves momentum, assessment, confidence, and completion metrics as the baseline.

Open the first step, review it, and select **I’ve completed this step**. Repeat for the guided example.

Select **Try the checkpoint**. For a reset Tunde, the target mission is **Find what is missing**:

- A blank sale should always become zero: **False**.
- Mean of known sales 10 and 20: **15**.

Report confidence and select **Check my understanding**. The app scores these actual answers. It does not insert the blueprint’s example result.

## 5. Show the evidence

The recovery view compares the preserved baseline against current momentum, actual assessment score, and reported confidence. It shows the weighted recovery components and outcome.

The data-cleaning competency is still **Developing** after its first mission. Complete its second checkpoint to demonstrate the full skill and unlock SQL. This distinction is intentional.

## 6. Show a different barrier

Return to **Demo lab**, select **Amina**, and simulate her challenge. Her shorter sessions and good scores point toward limited time. Confirm and compare the micro-mission plan.

Mariam demonstrates connectivity constraints with text-first content and a downloadable plan. David demonstrates relevance feedback and a goal-linked intervention.

## Optional failure branch

With a fresh Tunde recovery plan, deliberately answer the final checkpoint incorrectly. The result is **Intervention ineffective**, even if all steps were attempted.

Select **Check in again**. Confirm the same barrier to try its alternate strategy, or correct the barrier to select a different intervention category. The previous result and baseline remain in the database.

## New learner branch

Sign out and create a local account. Enter a goal, starting point, success criteria, time budget, and constraints. Complete the diagnostic and begin the first mission. This learner has independent progress and cannot access demo controls.

## Circle judge-demo extension

Before starting Tunde's recovery, open **My Circle**, choose **My Circle** visibility, and save. Create an invitation for **Tomi**, relationship **Sibling**. Open the copied link in a separate browser profile or private window and select **Join this Circle**. Keep that supporter inbox open. Invitations and joins must happen before the new milestone to receive its notification.

Continue the recovery demonstration above. After **Find what is missing**, complete **Clean a customer dataset**: answer **First and second**, then **120**. This demonstrates the full data-cleaning competency.

Return to Tomi's supporter inbox and reload (or let the visible page poll). Show **Data cleaning completed** and the demonstrated skill, with no assessment scores or recovery details. Click **Proud of you!** on the milestone. Return to Tunde's **My Circle** to show Tomi's encouragement, then mark it read.

Finish by choosing **Private** and saving. Reload the supporter page to show that the old invitation can no longer display the journey. Existing learner progress and the received encouragement remain intact. This is an in-app notification demo; email is optional and disabled in the local default setup.

## Two-course walkthrough

Sign in and show the course library. Data Analysis retains its existing progress; Introduction to Python starts separately. Select Python, set a Python goal, and finish its six-question diagnostic. Explain that this starting point applies only to Python.

Open **Say hello with Python** and answer **Hello** and **# Explain this step**. The first checkpoint passes and Python reaches 8%. Open **My Circle** to show its independent private settings. Select **Switch course** and return to Data Analysis: its prior lessons, goal, momentum, and Circle remain separate.

To demonstrate recovery in Python, select it again and open **Demo lab**. Simulate a challenge, confirm or correct the proposed barrier, and inspect the Comeback plan: its review, example, and checkpoint come from Python. For ordinary accounts, the engine uses actual course learning signals rather than demo simulation controls.

An administrator can use **Add a course** to open the draft-authoring workflow described in COURSES.md. The shipped catalog remains limited to the two requested courses.
